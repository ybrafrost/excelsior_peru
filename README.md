# Excelsior Perú - Cristal Templado Arquitectónico

Sitio web oficial y landing page comercial para **Excelsior Perú**, especialistas en mamparas, puertas apilables, plegables, de ducha y barandas de cristal templado de alta gama en Lima Metropolitana.

---

## 🚀 Ejecución en Localhost

El servidor web local ya se encuentra ejecutándose activamente:

- **URL Local:** [http://localhost:8000](http://localhost:8000)
- **Directorio del Proyecto:** `/Users/yuribracamonte/.gemini/antigravity/scratch/excelsior-web`

Para iniciar el servidor manualmente en cualquier momento desde la terminal:
```bash
cd /Users/yuribracamonte/.gemini/antigravity/scratch/excelsior-web
python3 -m http.server 8000
```

## 🎨 Características de Diseño & Front-End

- **Diseño Arquitectónico Minimalista & Glassmorphism:** Superficies translúcidas con `backdrop-blur`, contrastes elegantes y tipografía **Manrope** de alta legibilidad.
- **Micro-interacciones Interactivas:**
  - **Slider Antes vs. Después:** Comparador interactivo arrastrable de transformación arquitectónica (terraza residencial).
  - **Filtro dinámico de proyectos:** Clasificación instantánea por categorías (*Todos*, *Vivienda & Terrazas*, *Oficinas Corporativas*, *Comercial & Retail*).
  - **Acordeón FAQ:** Desplegables de preguntas frecuentes sobre precios, tiempos y normativas.
  - **Navegación Móvil Responsive:** Menú colapsable con accesos directos por ancla.
  - **Conversión Rápida a WhatsApp:** Botones fijos y de llamada a la acción con mensajes personalizados al número oficial de ventas.
  - **Formulario de Cotización:** Validación de campos y retroalimentación inmediata en pantalla.
